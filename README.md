# ERNotes

## 📌 Description

ERNotes is a full-stack web application for personal note management. It allows users to create, edit, organize, and delete notes with a clean and modern interface. The project was built to practice real-world full-stack development including authentication, cloud database integration, and deployment workflows.

## 🚀 What it does

- Create, edit, and delete notes
- Organize notes (active, favorites, trash)
- User authentication system
- Cloud-based data persistence
- Responsive and modern UI
- Full CRUD functionality

## 🧠 What I learned as a developer

- Full-stack architecture (frontend + backend separation)
- Building and consuming REST APIs
- Authentication and user session handling
- Working with cloud databases
- State management in React / Next.js applications
- Deploying real-world applications
- Structuring scalable project architecture

## 🛠️ Tech Stack

- Node.js
- Express
- Next.js
- Supabase
- Tailwind CSS
- TypeScript
- REST API
